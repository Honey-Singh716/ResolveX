# ResolveX

ResolveX is an issue and service management platform.

## Problem

Service requests and complaints are often scattered across
messages, calls, and manual registers.

## Planned Features

- User authentication and role-based access
- Ticket creation and assignment
- Status tracking and comments
- Admin analytics
- Notifications and audit history

## Planned Technology Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- ORM and migrations: SQLAlchemy + Alembic
- Testing: Pytest
- Deployment: Docker and CI/CD
